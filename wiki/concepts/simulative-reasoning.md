# Simulative Reasoning

## Definition

An agent decision-making approach where an agent uses a world model to mentally simulate multiple action sequences and their likely outcomes, then selects the action sequence with the best expected reward. Simulative reasoning contrasts with direct optimization algorithms that compute actions through analytical methods; instead, it relies on imagined experience generated by the world model.

## Why It Matters

Simulative reasoning is the core mechanism by which agents use world models for planning and decision-making. Rather than requiring direct access to the true environment (which is often unavailable or too expensive), agents simulate possible futures to guide action selection. This enables agents to anticipate consequences, explore alternatives, and plan multi-step strategies without executing actions in the real world. Simulative reasoning is more flexible and interpretable than black-box optimization and aligns with how humans intuitively reason about decisions.

## Variants / Approaches

- **Deterministic rollout**: Simulate single most-likely futures given candidate actions
- **Stochastic rollout**: Simulate distributions over futures, accounting for uncertainty
- **Multi-path exploration**: Explore multiple candidate action sequences in parallel
- **Monte Carlo tree search**: Efficiently search over action space using simulated rollouts
- **Goal-conditioned simulation**: Simulate backward from desired goal to identify viable action sequences
- **Counterfactual reasoning**: Simulate "what-if" scenarios to understand causal relationships
